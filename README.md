# 💪 V R Fitness – Modern Gym Website

V R Fitness is a modern and interactive gym website designed to provide visitors with a premium fitness experience. It features a stylish dark theme, animated sections, an AI Fitness Coach interface, and membership plans.

## ✨ Features

- **Modern Design:** Premium dark theme with neon red and electric blue accents.
- **Responsive Layout:** Designed for a smooth experience across desktop and mobile screens.
- **Animated Hero Section:** Background workout video and smooth text animations.
- **AI Fitness Coach:** Interactive chat interface for workout suggestions, diet tips, and BMI-related guidance.
- **Membership Plans:** Three plans – Basic, Premium, and Elite – with different features and pricing.
- **Membership Registration:** Select a plan and enter your name and email.
- **Interactive UI:** Smooth transitions, pop-up registration form, and animated elements.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- React.js
- Framer Motion

## 🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the website and its interactive features.

## 🎯 Project Goal

The goal of this project is to create a modern digital platform for a fitness club, making it easy for visitors to explore fitness services, interact with a virtual coach interface, and view membership options.
